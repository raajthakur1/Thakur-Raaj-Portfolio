Design and Planning

Determining Networks Using IPv4 Addresses and Subnet Masks in Packet Tracer

In this activity, Cisco Packet Tracer was used to construct a LAN in order to determine how devices communicate based on their IP address and subnet mask.

Part 1: Build the Network

A network was created with 3 PCs (labeled PC0, PC1, and PC2) and one switch. All the PCs were connected directly to the switch via copper straight-through cables. Then, the following IP configuration was set for the devices:

Device IP Address Subnet Mask
PC0 192.168.1.10 255.255.255.0
PC1 192.168.1.25 255.255.255.0
PC2 192.168.2.10 255.255.255.0

Part 2: Investigate Communication:

On each PC, ping commands were used for the following tests:

PC0 (192.168.1.10) → PC1 (192.168.1.25) PC0 (192.168.1.10) → PC2 (192.168.2.10)
